What it does
Everything you need, nothing you don't

Real-time search

Searches title, URL, and tags simultaneously — including mid-word matches. Results update as you type.

Tags stored in the bookmark

Tags live inside the bookmark title (Title | tag1, tag2), so they sync across all your devices via your Google account automatically.

Duplicate detection

Automatically finds duplicate URLs, stripping tracking parameters (UTM, fbclid) and anchors before comparing.

CSV export & import

Export all bookmarks (title, URL, tags) as a UTF-8 CSV compatible with Excel and Google Sheets. Import works the same way.

Inbox for untagged bookmarks

Review every bookmark without a tag in one place, then organize it when you have time.

Bulk actions

Select multiple bookmarks to add tags, move them to a Chrome folder, or delete them with history-based undo.

Safe bookmark creation

Normalized URLs prevent accidental duplicates. Add new tags to the existing bookmark instead.

Keyboard-first management

Navigate with J/K, open with Enter, select with X, and edit, tag, copy, or delete without reaching for the mouse.

Privacy Policy

Last updated: November 2026 · Applies to version 1.0.0 and later

Summary: Ponad Kodem Bookmarks stores settings, recent tags, and change history locally using chrome.storage.local. When favicons are enabled, bookmark domains are sent to Google's favicon service. The extension developer does not receive this data.

What data we store

Settings, recent tags, and change history are stored exclusively in your browser's local storage.

KeyContentsPurpose
bm_settingsFavicon display preferencePersist user preferences
bm_historyLast 30 edit, tag, move, and delete operationsUndo support
bm_recent_tagsLast 8 tags used while adding bookmarksShow local tag suggestions
bm_view_prefsGroup mode and sort orderRestore view between sessions
bm_pending_addTitle + URL of bookmark being addedPass data from background to popup (cleared immediately)

Permissions used

PermissionWhy it's needed
bookmarksRead, create, edit, move, and delete Chrome bookmarks
storageSave preferences, recent tags, and change history locally
tabsRead the active tab URL/title when saving via Alt+Shift+D
https://www.google.com/*Retrieve favicons when favicon display is enabled

Optional network feature

Favicon display sends bookmark domains to Google's favicon service. It is disabled by default.

Data sharing

We do not collect, sell, or rent any data. Bookmark domains are sent to Google only when favicon display is enabled. No analytics, crash reporting, or telemetry of any kind.

Data deletion

Go to chrome://extensions, find Ponad Kodem Bookmarks and click Remove to delete all stored data.
