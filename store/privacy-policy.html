Ponad Kodem Bookmarks

Privacy Policy

Last updated: November 2026  ·  Applies to Chrome extension version 1.0.0 and later

Summary: Ponad Kodem Bookmarks stores settings, recent tags, and change history locally using chrome.storage.local. When favicons are enabled, bookmark domains are sent to Google's favicon service. The extension developer does not receive this data.

1. What data we store

Settings, recent tags, and change history are stored exclusively in your browser's local storage (chrome.storage.local). The optional favicon request is described below.

KeyWhat it containsPurpose
bm_settings Favicon display preference Persist user preferences
bm_history Last 30 bookmark operations (edit / tag / move / delete) with timestamps Undo / audit trail
bm_recent_tags Last 8 tags used while adding bookmarks Show local tag suggestions
bm_view_prefs UI preferences: group mode and sort order Restore view between sessions
bm_pending_add Title and URL of a bookmark being added via keyboard shortcut Pass data from background service worker to popup (cleared immediately after use)

2. Permissions used

PermissionWhy it's needed
bookmarks Read, create, edit, move, and delete Chrome bookmarks via the native API
storage Save user preferences, recent tags, and change history locally via chrome.storage.local
tabs Read the URL and title of the active tab when adding a bookmark via keyboard shortcut (Alt+Shift+D)
host_permissions: https://www.google.com/* Retrieve favicons from Google's favicon service when the user enables favicon display.

3. Optional network feature

When favicon display is enabled, the bookmark domain is sent to Google's favicon service (www.google.com/s2/favicons) to retrieve the corresponding icon.

4. Data sharing

We do not collect, sell, or rent any of your data. Bookmark domains are sent to Google only when favicon display is enabled. No analytics, crash reporting, or telemetry services are used. No data is transmitted to the extension developer.

5. Data retention & deletion

All locally stored data is retained until you remove it. You can clear all extension data at any time by going to chrome://extensions, finding Ponad Kodem Bookmarks, and clicking Remove, or by clearing site data for the extension in Chrome settings.

6. Children's privacy

This extension does not knowingly collect any information from children under the age of 13. It does not involve any data collection beyond what is described in this policy.

7. Changes to this policy

If this policy changes materially, the updated version will be published at this URL and the extension version number will be incremented. Continued use of the extension after such changes constitutes acceptance of the updated policy.

8. Contact

If you have questions about this privacy policy, please open an issue in the extension's source repository or contact the developer directly via the Chrome Web Store developer page.
